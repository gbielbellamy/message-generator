# Space Role Generator (CLI Tool)

A simple Node.js command-line application that generates random space-themed messages.

Each execution assigns a **random space role** and a **mission**, creating a fun and dynamic output directly in the terminal.

---

## 🎯 Features

- Random space role generation
- Random mission assignment
- Space-themed output messages
- Lightweight CLI tool
- No external dependencies

---

## 🛠️ Tech Stack

- Node.js
- JavaScript (ES6)

---

## 📦 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/space-role-generator.git
Navigate into the project folder:
cd space-role-generator
Run the script:
node script.js
