# 🚀 Space Role Generator

A CLI tool that randomly assigns you a space role and a unique mission. Built with Node.js as a fun exercise in randomness, string manipulation, and command-line application design.

---

## 📋 Prerequisites

- [Node.js](https://nodejs.org/) v14 or higher

---

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/space-role-generator.git
```

2. Navigate into the project folder:

```bash
cd space-role-generator
```

---

## ▶️ Usage

```bash
node script.js
```

---

## 💡 Example Output

```
You are a Quantum Navigator.
Mission: Stabilize an unstable wormhole near Sector 7G.
```

This project was built as a fun exercise in:
